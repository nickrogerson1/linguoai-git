<h1 align="center">LinguoAI – AI-powered English language helper app</h1>

### About This Project (Intro)
This app helps English language learners improve their English. It currently consists of three principal features.
1.	An AI-powered IELTS writing part 2 section scorer
2.	An AI-powered written English corrector
3.	An AI-powered written English improver

### What it was built with / Tech Stack
This app was built with Python, the Django Web Framework and PostgreSQL. JQuery and Bootstrap were also used for frontend development.
Chart.js was used to handle dashboard features.
NLTK and PyMuPDF were used to provide PDFs and Python DOCX for Word documents.
Websockets were implemented with Daphne and Django Channels to keep an open connection between the client.
Wagtail was used to set up the blog.

### Key Features
-	AI-driven (OpenAI) platform providing accurate IELTS writing scores and grammar corrections for non-native English speakers.
-	Users can download their results as either a DOCX or PDF.
-	Gorgeous dashboard powered by Chart.js.
-	Websockets provide real-time browser updates.
-	Payments processed fast and securely by Stripe.

### What problems it solves
IELTS tests are really expensive, costing up to £220 in the UK and in excess of that in countries like China. This app aimed to provide users with a way to test their writing skills before paying for and taking an actual test.
